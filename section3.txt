Section 3: eQTL analysis
========================

Question 1 - Preprocessing
--------------------------
Both datasets were downloaded from GEO with GEOparse, and no
re-normalisation was applied: the analysis uses the expression values
exactly as deposited in GEO, which are already normalised. In both
datasets an array is one hybridised RNA sample, and a strain typically
has two arrays (one male, one female), which are averaged only at the
end (step h).
  Hypothalamus, GSE36674: Affymetrix Mouse Gene 1.0 ST platform
  (GPL6246), 89 arrays. The deposited values are RMA-normalised log2
  expression intensities.
  Liver, GSE17522: Agilent G4121A two-colour platform (GPL6466),
  122 arrays. The deposited values are LOWESS-normalised log2 ratios of
  each sample against a common reference RNA.
Of these, the 79 arrays per tissue that belong to BXD strains present in
the genotype file enter the analysis (step a-b), and the filtering steps
c-f operate on this probes x arrays matrix, before the per-strain
averaging of step h.

a-b) Input matrix. In GEO, a series (GSE accession) is one deposited
   dataset, and a sample (GSM accession) is one array within it. A probe
   is one measured sequence on the array, and several probes can target
   the same gene (they are collapsed in step f). For each of the two
   series, the VALUE column of every sample was joined into a
   probes x arrays matrix. The strain of each array was
   read from the 'strain:' field of the sample characteristics. The matrix
   was merged with the platform's annotation table (the GPL accession) to
   obtain, per probe, the gene symbol, chromosome and position.
   - Hypothalamus: only 'main' transcript clusters (this platform's probe
     unit) were kept (28,101; the rest are normalisation/control probes).
     The platform has no plain gene-symbol column, so the symbol was
     parsed from the 'gene_assignment'
     field ('RefSeq // Symbol // name // cytoband // Entrez /// ...'). When
     a cluster is assigned to several genes (~3,800 clusters) the first
     entry was used, as it is Affymetrix's primary assignment. Discarding
     these clusters would lose genuine genes.
   - Liver: non-control probes were kept (20,868). GENE_SYMBOL and the
     probe location 'chrN:start-end' were used.
   Only arrays of BXD strains present in the genotype file were kept
   (79 arrays in each tissue). Dropped: the parental strains, F1 crosses,
   BXD92A (hypothalamus) and BXD11TY (liver), which are not in the
   genotype file.
   Genome build (the version of the reference genome that coordinates
   refer to; positions are comparable only within one build): the
   hypothalamus platform is annotated on GRCm38 (mm10), whereas the
   genotype file and the liver platform use NCBI Build 37 (mm9).
   Hypothalamus gene positions were converted to mm9 with UCSC's liftOver
   mapping (pyliftover). Of these, 124 genes did not map and have
   no position.
   Genes without a position (124 hypothalamus, 80 liver) are kept in the
   eQTL scan but cannot be classified as cis or trans.
c) Rows without a gene symbol were removed: 26,710 probes remained in the
   hypothalamus, 19,272 in the liver.
d) Low maximal value: the two platforms are on different scales
   (log2 intensities vs. log2 ratios), so a common absolute threshold is
   not meaningful. The threshold was set at the 10th percentile of the
   per-probe maximal values of each dataset:
   max >= 6.10 (hypothalamus; the bottom tail of the RMA distribution,
   i.e. probes at background level in every array) and max >= -0.68
   (liver; probes at least ~1.6-fold below the reference in every array).
   Remaining: 24,042 and 17,348 probes.
   [FIGURE: notebook Section 3.1, top row of the figure - panels
    "hypothalamus: maximal value per probe" and "liver: maximal value per
    probe"; red line = threshold]
e) Low variance: of the probes remaining after step d, those in the lowest
   10% of the variance distribution (variance across the 79 arrays;
   var < 0.0089 hypothalamus, < 0.021 liver) were removed. These probes
   are at the level of technical replicate noise of the arrays (SD ~0.1
   log2 units), so they cannot show an eQTL and only add to the
   multiple-testing burden. A 10% cut, symmetric to step d, removes this
   noise-floor tail without discarding genes with genuine but modest
   variation. Remaining: 21,637 and 15,613 probes.
   [FIGURE: notebook Section 3.1, bottom row of the figure - panels
    "hypothalamus: log10 variance per probe (after step d)" and "liver:
    log10 variance per probe (after step d)"; red line = threshold]
f) Multiple probes per gene were collapsed by keeping the probe with the
   highest variance, which is the most informative for an association
   test. Averaging probes would dilute a well-measured probe with poorly
   hybridising or saturated ones. Result: 19,577 genes (hypothalamus) and
   14,659 genes (liver).
g) The genotype file was restricted to the strains present in each
   expression dataset (45 hypothalamus, 40 liver). Consecutive SNPs with an
   identical genotype vector across these strains (unknown calls counted
   as a distinct value) give identical association statistics, so each run
   of identical neighbours was represented by one SNP: 1,598 representative
   SNPs for the hypothalamus strains and 1,403 for the liver strains (out
   of 3,796). Which SNP represents a run does not affect the test, only
   the position assigned to it, and the first (most proximal) SNP was
   used.
   The genomic span of each run was also recorded (median 0.4-0.5 Mb, up
   to ~10 Mb), so that SNP-gene distances for the cis/trans classification
   are measured to the run interval rather than to a single arbitrary SNP.
h) Arrays of the same strain were averaged regardless of sex (34 of the 45
   hypothalamus strains and 38 of the 40 liver strains have one array of
   each sex; the rest are single-sex), giving the final input matrices:
   19,577 genes x 45 strains (hypothalamus) and 14,659 genes x 40 strains
   (liver).


Question 2 - eQTL association test and choice of the final eQTL collection
--------------------------------------------------------------------------
Test: the association test of Section 2 (eQTL mapping = QTL mapping with
the expression of a gene as the trait): linear regression of the strain
means of a gene on the genotype (B = 0, H = 1, D = 2) and F-test of the
regression, for every gene x representative SNP pair. Hypothalamus:
19,577 x 1,598 = 31.3 million tests; liver: 14,659 x 1,403 = 20.6 million.

Multiple testing: BH-FDR was applied once over all gene x SNP tests of a
tissue (q-value per pair), rather than per gene, so that a single
false-discovery level applies to the whole eQTL collection and the number
of significant eQTLs is well defined.

Selection of eQTLs: every (SNP, gene) pair with q < 0.05 is an eQTL of
that gene. Genes with no significant SNP were excluded. We did not reduce
each gene to its single best SNP, since that would assume that all
significant SNPs of a gene mark the same locus, which need not hold (a
gene can have a cis eQTL and an independent trans eQTL). The eQTL position
is the representative SNP together with the span of its run of identical
SNPs.
Caveat: neighbouring SNPs that are highly (but not perfectly) correlated
across the strains are kept as separate eQTLs, so a single locus is
typically represented by several SNPs (median 4 significant SNPs per gene,
max 23), which inflates the number of eQTLs relative to the number of
independent loci.

Result (results/eqtl_<tissue>.csv):
  Hypothalamus: 7,509 eQTLs (SNP-gene pairs) for 1,416 genes (of 19,577
                tested) at 1,317 distinct SNPs (of 1,598).
  Liver:        6,804 eQTLs for 1,285 genes (of 14,659 tested) at 1,209
                distinct SNPs (of 1,403).


Question 3 - Results analysis
-----------------------------
Definitions: an eQTL (SNP-gene pair) is cis-acting if the gene is on the
same chromosome within 2 Mb of the SNP's run of identical markers, and
trans-acting otherwise. Pairs whose gene has no genomic position are
'unknown'. Counts below are per tissue. Figures are listed in [FIGURE: ...]
lines by their notebook subsection and panel title. Each figure has one
panel (or one copy) per tissue.

a) Number of eQTLs, cis vs trans
                                 Hypothalamus      Liver
   eQTLs (SNP-gene pairs)              7,509      6,804
     cis                        3,066 (41%)   2,320 (34%)
     trans                      4,434 (59%)   4,451 (65%)
     unknown                             9         33
   distinct eQTL SNPs                  1,317      1,209
     cis only / trans only / both  245/388/681  184/364/652
   genes with an eQTL                  1,416      1,285
     with a cis / a trans eQTL     1,128/1,112    872/1,087
   Most eQTL SNPs act both in cis (on a nearby gene) and in trans (on
   distant genes), and ~80% of eQTL genes have a cis eQTL.

b) Genes per eQTL. Of the representative SNPs, 1,317 (hypothalamus) and
   1,209 (liver) are associated with at least one gene (281 and 194 with
   none). The distribution is heavily right-skewed: 20% of the eQTL SNPs
   are associated with a single
   gene and about half with at most 3 genes (49% / 46%), the median is 4
   and the mean 5.7 / 5.6, while 14% of the eQTL SNPs are associated with
   more than 10 genes, up to 50 (hypothalamus) and 69 (liver). Most eQTLs
   thus affect one or a few genes, and a small tail of SNPs affects many -
   the trans hotspots examined in (e). The two tissues are strikingly
   similar in this respect (all fractions within 3 percentage points,
   same median and nearly the same mean), despite different platforms,
   strain sets and gene sets, suggesting that the shape of the
   distribution reflects the genetic architecture of expression in BXD
   mice rather than tissue-specific features.
   [FIGURE: notebook Section 3.3(b) - histograms "hypothalamus: genes per
    eQTL" and "liver: genes per eQTL"; log-scale y axis]

c) Along the genome, the number of associated genes per
   SNP is not uniform: most SNPs have a few genes, and a handful of
   regions stand out - hypothalamus: distal Chr 17 (~22-37 Mb; up to 50
   genes), Chr 11 (~65 Mb), Chr 2 (~115-135 Mb), Chr 1 and Chr 7; liver:
   Chr 12 (~104-110 Mb; 69 genes), Chr 17, Chr 2, Chr 4 and Chr 8. These
   are the trans hotspots analysed in (e). Adjacent SNPs in a region show
   similar counts because they are in linkage.
   [FIGURE: notebook Section 3.3(c) - panels "hypothalamus: number of
    associated genes per representative SNP" and "liver: number of
    associated genes per representative SNP"; one vertical line per SNP,
    chromosomes shaded alternately]

d) P-value distributions. Cis eQTLs are much stronger than trans eQTLs:
   median -log10(P) 7.2 vs 6.1 (hypothalamus) and 7.5 vs 6.0 (liver).
   The cis distribution has a long tail (up to 10^-29 / 10^-34) whereas
   trans P-values pile up just above the significance boundary
   (-log10 P ~ 4.9). This matches the lecture's observation that cis
   eQTLs tend to have larger effects than trans eQTLs: a single
   regulatory variant acts directly on the nearby gene, whereas trans
   effects are indirect and diluted.
   [FIGURE: notebook Section 3.3(d) - density histograms "hypothalamus: cis
    vs trans eQTLs" and "liver: cis vs trans eQTLs"; blue = cis, red =
    trans, x axis = -log10 P of the eQTL]

e) eQTL map (SNP position vs gene position). Cis eQTLs
   form a sharp diagonal (gene at the SNP's position) in both tissues.
   Trans eQTLs are scattered off the diagonal and concentrate in vertical
   bands - SNPs associated with many distant genes, i.e. trans-acting
   hotspots. Hotspots were defined, as in Brem et al. (2002) and Morley et
   al. (2004), against a null in which the trans eQTLs are distributed
   uniformly over the representative SNPs. The number of trans genes per
   SNP is then binomial, approximated by Poisson with mean = trans eQTLs /
   SNPs (2.8 hypothalamus, 3.2 liver). A SNP is a hotspot if its trans
   count exceeds the value reached with probability < 0.001 under this
   null: > 9 genes (hypothalamus) and > 10 genes (liver). Hotspot SNPs
   within 5 Mb were merged into regions. The null
   assumes independent eQTLs and is therefore lenient (see Section 5).
   The threshold serves to rank and label candidate hotspots, and the
   major ones (20-64 trans genes) stand out under any reasonable rule.
   Hypothalamus: 118 hotspot SNPs in 29 regions, the strongest being
     Chr 17: 22-37 Mb (peak 40 trans genes, rs13482930),
     Chr 11: 65-75 Mb (27), Chr 7: 71-74 Mb (24), Chr 17: 9-12 Mb (23),
     Chr 12: 27-29 Mb (22), Chr 2: 114-136 Mb (22).
   Liver: 93 hotspot SNPs in 30 regions, with one dominant hotspot at
     Chr 12: 104-110 Mb (peak 64 trans genes, rs13481620), then
     Chr 17: 27-41 Mb (22), Chr 2: 107-126 Mb (21), Chr 8: 75-78 Mb (20),
     Chr 11: 72-75 Mb (19).
   Several hotspot regions are shared by the two tissues (Chr 17 ~27-37
   Mb, Chr 11 ~65-75 Mb, Chr 2, Chr 17 ~9-12 Mb, Chr 1 ~126-130 Mb),
   whereas the Chr 12 hotspot is liver-specific.
   [FIGURE: notebook Section 3.3(e) - one figure per tissue, "hypothalamus:
    eQTL map (each point is one SNP-gene eQTL)" and "liver: eQTL map (each
    point is one SNP-gene eQTL)". Upper panel: SNP position (x) vs gene
    position (y), blue = cis, red = trans. Lower panel "trans genes":
    number of trans-associated genes per SNP along the genome, dashed line
    = hotspot threshold, labels = hotspot regions]

שאלה 2 - מבחן האסוציאציה ל-eQTL ובחירת אוסף ה-eQTLs הסופי
----------------------------------------------------------
מבחן: מבחן האסוציאציה של חלק 2 (מיפוי eQTL = מיפוי QTL עם ביטוי של גן
כתכונה): רגרסיה ליניארית של ממוצעי הזנים של גן על הגנוטיפ
(B = 0, H = 1, D = 2) ומבחן F של הרגרסיה, עבור כל זוג גן x SNP מייצג.
היפותלמוס: 19,577 x 1,598 = 31.3 מיליון מבחנים; כבד:
14,659 x 1,403 = 20.6 מיליון.

השוואות מרובות: תיקון BH-FDR הוחל פעם אחת על כל מבחני הגן x SNP של
רקמה (ערך q לכל זוג), ולא לכל גן בנפרד, כך שרמת תגליות-שווא אחת חלה על
אוסף ה-eQTL כולו ומספר ה-eQTLs המובהקים מוגדר היטב.

בחירת ה-eQTLs: כל זוג (SNP, גן) עם q < 0.05 הוא eQTL של אותו גן. גנים
ללא SNP מובהק הוצאו. לא צמצמנו כל גן ל-SNP הטוב ביותר שלו, משום שצמצום
כזה מניח שכל ה-SNPs המובהקים של גן מסמנים את אותו לוקוס, וזה אינו
בהכרח נכון (לגן יכולים להיות eQTL מסוג cis ו-eQTL בלתי-תלוי מסוג
trans). מיקום ה-eQTL הוא ה-SNP המייצג יחד עם מוטווח רצף ה-SNPs הזהים
שלו.
הסתייגות: SNPs שכנים בעלי מתאם גבוה (אך לא מושלם) על פני הזנים נשמרים
כ-eQTLs נפרדים, ולכן לוקוס יחיד מיוצג בדרך כלל על-ידי כמה SNPs (חציון
4 SNPs מובהקים לגן, לכל היותר 23), מה שמנפח את מספר ה-eQTLs ביחס למספר
הלוקוסים הבלתי-תלויים.

תוצאה (results/eqtl_<tissue>.csv):

             שנבדקו) ב-1,317 SNPs שונים (מתוך 1,598).
  כבד:       6,804 eQTLs עבור 1,285 גנים (מתוך 14,659) ב-1,209 SNPs
             שונים (מתוך 1,403).

   אותו חציון וכמעט אותו ממוצע), למרות פלטפורמות, קבוצות זנים וקבוצות
   גנים שונות - מה שמרמז שצורת ההתפלגות משקפת את הארכיטקטורה הגנטית של

d) התפלגויות ערכי P. \u200FeQTLs מסוג cis חזקים בהרבה מ-trans: חציון
   \u200E-log10(P)\u200E הוא 7.2 לעומת 6.1 (היפותלמוס) ו-7.5 לעומת 6.0 (כבד).
   להתפלגות ה-cis זנב ארוך (עד 10^-29 / 10^-34) ואילו ערכי ה-P של
   trans נערמים מעט מעל גבול המובהקות (\u200E-log10 P ≈ 4.9). הדבר תואם את
   התצפית מההרצאה של-eQTLs מסוג cis נטייה לאפקטים גדולים יותר מאשר
   ל-trans: וריאנט רגולטורי יחיד פועל ישירות על הגן הסמוך, בעוד השפעות
   trans עקיפות ומדוללות.
   [איור: מחברת סעיף 3.3(d) - היסטוגרמות צפיפות "hypothalamus: cis vs
    trans eQTLs" ו-"liver: cis vs trans eQTLs"; כחול = cis,
    אדום = trans, ציר x = \u200F-log10 P של ה-eQTL]

e) מפת eQTL (מיקום SNP מול מיקום גן). ה-eQTLs מסוג cis יוצרים אלכסון
   חד (הגן במיקום ה-SNP) בשתי הרקמות. ה-eQTLs מסוג trans מפוזרים מחוץ
   לאלכסון ומתרכזים בפסים אנכיים - SNPs המקושרים לגנים מרוחקים רבים,
   כלומר hotspots מסוג trans. ה-hotspots הוגדרו, כמו אצל Brem et al.\u200F
   (2002) ו-Morley et al.\u200F (2004), מול מודל אפס שבו ה-eQTLs מסוג trans
   מפוזרים אחיד על פני ה-SNPs המייצגים. מספר גני ה-trans לכל SNP הוא
   אז בינומי, מקורב על-ידי פואסון עם ממוצע = מספר trans eQTLs / מספר
   SNPs (\u200F2.8 בהיפותלמוס, 3.2 בכבד). SNP הוא hotspot אם ספירת ה-trans
   שלו עולה על הערך המושג בהסתברות < 0.001 תחת מודל אפס זה: יותר מ-9
   גנים (היפותלמוס) ויותר מ-10 גנים (כבד). hotspot-SNPs במרחק עד 5 Mb
   אוחדו לאזורים. מודל האפס מניח eQTLs בלתי-תלויים ולכן הוא מקל (ראו
   חלק 5). הסף משמש לדירוג ולסימון hotspots מועמדים, והבולטים שבהם
   (20-64 גני trans) בולטים תחת כל כלל סביר.
   היפותלמוס: 118 hotspot-SNPs ב-29 אזורים, החזקים שבהם
     כרומוזום 17: 22-37 Mb (שיא 40 גני trans, \u200Frs13482930),
     כרומוזום 11: 65-75 Mb (27), כרומוזום 7: 71-74 Mb (24),
     כרומוזום 17: 9-12 Mb (23), כרומוזום 12: 27-29 Mb (22),
     כרומוזום 2: 114-136 Mb (22).
   כבד: 93 hotspot-SNPs ב-30 אזורים, עם hotspot דומיננטי אחד
     בכרומוזום 12: 104-110 Mb (שיא 64 גני trans, \u200Frs13481620), ואחריו
     כרומוזום 17: 27-41 Mb (22), כרומוזום 2: 107-126 Mb (21),
     כרומוזום 8: 75-78 Mb (20), כרומוזום 11: 72-75 Mb (19).
   כמה מאזורי ה-hotspot משותפים לשתי הרקמות (כרומוזום 17 ~27-37 Mb,
   כרומוזום 11 ~65-75 Mb, כרומוזום 2, כרומוזום 17 ~9-12 Mb,
   כרומוזום 1 ~126-130 Mb), ואילו ה-hotspot בכרומוזום 12 ייחודי לכבד.
   [איור: מחברת סעיף 3.3(e) - איור אחד לכל רקמה, "hypothalamus: eQTL
